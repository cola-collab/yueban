# 月伴

月伴是无账户的静态经期关怀网页。iPhone“健康”App 承担系统经期通知；月伴只在本机估算参考日期、提供护理建议和可选的 `.ics` 日历备份。两套预测不会自动同步，月伴不能读取“健康”App 的通知状态。一次设置后，使用者仅在愿意时校准实际开始日期；没有新的真实日期，长期推算可能偏移。

正式网址：<https://cola-collab.github.io/yueban/>。无需 Mac、Apple 开发者账户或提醒服务器。

## 使用

1. 在 iPhone Safari 打开网站，需要时选择“分享”→“添加到主屏幕”。
2. 点首页“设置经期提醒”，按页面步骤在“健康”App 的“经期追踪”中开启月经预测和月经通知。页面上的确认按钮只记录使用者自己的确认，不代表网页检测到了系统状态。
3. 可另填最近实际开始日期及通常周期间隔，让月伴显示本机估算；月伴设置不会写入“健康”App。
4. 如使用日历备选，导出后必须自行导入并在事件中核对提醒。更新月伴日期不会自动删除旧日历事件，建议把导入事件放在单独日历中。两条渠道不建议默认同时使用。

如果在一台 iPhone 上没有“添加日程”，在提醒页下载不含真实经期日期的单事件测试文件；将**同一文件**分享给另一台手机，对比打开入口、是否出现添加操作、日历是否有事件、锁屏是否收到通知。不能因文件已下载就认为提醒已开启。

## 开发与发布

本目录是唯一源目录。使用原生 HTML、CSS、JavaScript 和本地打包的 Open Props、Phosphor SVG；不依赖外部 CDN。`dist/` 由 `node build.mjs` 生成，`node build.mjs --check` 核对副本一致。用 `node --test logic.test.mjs` 验证日期与日历逻辑。开发预览可用 `python -m http.server 18765`，不能直接双击 HTML 来测试 Service Worker。

发布时以公开仓库当前 `main` 为基线，把 `dist/` 内容作为 GitHub Pages 根目录。不要将真实经期日期、设置备份或个人测试文件提交到公开仓库；本地先检查版本号、隐私文案和构建一致性。更新 `sw.js` 的缓存版本，检查离线页面及旧缓存清理。

本机设置沿用 `yueban.settings.v1`，兼容旧备份；旧的“已导出”状态不会迁移为“已收到提醒”。若浏览器拒绝写入，页面显示数据可能丢失的提示。

## 隐私与限制

填写的日期只存于当前浏览器 `localStorage`，月伴没有账户、应用后端、广告或分析代码。GitHub Pages 托管方可能记录访问日志。清理浏览器数据、切换 Safari 与主屏幕入口或更换手机时，设置可能不共享或丢失。网页不会自动知道月经是否开始、是否结束，也不能核验苹果通知到达。日历事件使用导入设备的当地时间；跨时区旅行后应核对事件时间。

护理信息依据页面所列 NHS、Apple 等官方来源，于 2026-10-08 核查；它不能替代诊断、药盒说明或医生建议。
